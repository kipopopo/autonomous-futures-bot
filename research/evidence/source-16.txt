## Change Multi-Assets Mode (TRADE)[](https://developers.binance.com/docs/derivatives/usds-margined-futures/trade/rest-api/Change-Initial-Leverage#change-multi-assets-mode)

POST

/fapi/v1/multiAssetsMargin

https://fapi.binance.com

This is a signed endpoint and a **signature** must be included in the request parameters.Learn more about how to generate a valid **signature** in the [Endpoint Security Type](https://developers.binance.com/en/docs/products/derivatives-trading-usds-futures/general-info#endpoint-security-type)

### Change Multi-Assets Mode (TRADE) › Request Weight[](https://developers.binance.com/docs/derivatives/usds-margined-futures/trade/rest-api/Change-Initial-Leverage#change-multi-assets-mode/request-weight)

This endpoint consumes IP-based request weight. Heavier endpoints consume more of your IP rate limit capacity.

Learn more in the [Rate limits](https://developers.binance.com/en/docs/products/derivatives-trading-usds-futures/general-info#limits) section.

​string·required

An API Key is required to access this endpoint and must be included in the request headers. To create an API Key, refer to: [https://www.binance.com/en/support/faq/detail/360002502072](https://www.binance.com/en/support/faq/detail/360002502072).

### Change Multi-Assets Mode (TRADE) ›Request Body[](https://developers.binance.com/docs/derivatives/usds-margined-futures/trade/rest-api/Change-Initial-Leverage#change-multi-assets-mode/request-body)

`multiAssetsMargin`

​string·required

"true": Multi-Assets Mode; "false": Single-Asset Mode

Example:true

`timestamp`

​integer·int64·required

Unix timestamp in milliseconds used to sign the request. The value must reflect the current client time and is validated by the server for signed endpoints.

Example:1770736694138

`recvWindow`

​integer·int64·max: 60000

Example:5000
