## Account Information V2 (USER_DATA)[](https://developers.binance.com/docs/derivatives/usds-margined-futures/account/rest-api/Notional-and-Leverage-Brackets#account-information-v2)

Get current account information. User in single-asset/ multi-assets mode will see different value, see comments in response section for detail.

GET

/fapi/v2/account

https://fapi.binance.com

### Account Information V2 (USER_DATA) ›Authorization[](https://developers.binance.com/docs/derivatives/usds-margined-futures/account/rest-api/Notional-and-Leverage-Brackets#account-information-v2/authorization)

This is a signed endpoint and a **signature** must be included in the request parameters.Learn more about how to generate a valid **signature** in the [Endpoint Security Type](https://developers.binance.com/en/docs/products/derivatives-trading-usds-futures/general-info#endpoint-security-type)
