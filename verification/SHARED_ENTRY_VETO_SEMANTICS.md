## Defect and boundary

Creator condition-shaped `StrategySpec.vetoes` were ignored by `CausalFeatureSignalEvaluator`; the paper conviction path only interpreted an ADX substring and ignored other rules. This is an evaluator defect, not proof that the previously rejected strategies would qualify after a different evaluation. Original campaign artifacts, outcomes, reservations, approvals and ledgers remain unchanged; no historical rerun or attestation repair.

The bounded native comparison parser is reused. Declared supported veto features must be available and finite; any true rule, unavailable value, or nonfinite value blocks entries. Compound expressions retain the native parser's existing connector semantics; multiple veto rules combine with OR. Malformed/undeclared rules fail cached evaluation with `DataQualityError` and deny paper-entry conviction. Nonfinite literal thresholds now reject in the shared parser. Opaque legacy labels are not treated as no-op market conditions.

Raw directional signals and explicit exit conditions are intentionally preserved. `entry_vetoed` is an entry gate, not a modified direction: cached simulation validates its optional binary values before any accounting and applies it only when opening. Existing direct signal-only fixtures without a candidate/veto column retain their original behavior. Paper entry conviction reuses the same helper instead of the former ADX shortcut. Open paper trades request `exits_only=True`: this skips entry-rule veto validation but returns an all-blocked entry gate, preserving candidate-bound strategy/reversal exits even if a legacy veto label is invalid. Protective stops, take profits, trailing, forced-final close and accounting policies are unchanged.

Synthetic cached-execution fixtures and the two deterministic/demo-only Creator transports were migrated from opaque labels or undeclared references to declared impossible conjunctions. Hot-reload/reversal test wrappers now forward the explicit exit-only keyword rather than silently testing the exception fallback. No persisted production/historical artifact was rewritten; no risk, costs, qualification, admission or epoch authority changed. Raw `signal`/signal-count diagnostics alone are never permission or execution evidence.
