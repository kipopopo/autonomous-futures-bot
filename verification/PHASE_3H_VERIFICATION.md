# Phase 3h Verification — Immutable Completed Learner-Training Evidence

**Status: GREEN**

**Scope:** backend-only immutable evidence envelope for an explicit learner trainer output

**Safety boundary:** cached-only, paper-safe, testing-only, no promotion or execution authority

## Contract

Phase 3h adds `LearnerTrainingEvidence`, a separate immutable envelope that binds:

```text
verified prepared LearnerRun
→ source LearnerArtifact hash/reference
→ explicit trainer-produced output LearnerArtifact hash/reference
```

The envelope is completed-training provenance only. It does not contain model-quality
metrics, qualification, promotion, paper activation, or order authority.

The contract verifies:

- prepared learner-run content hash;
- source learner artifact hash and candidate binding;
- output learner artifact hash, model-file hash, and candidate binding;
- exact learner/candidate/bundle/dataset provenance;
- input window IDs, symbols, features, and prepared training range;
- relative POSIX references with root containment;
- UTC timestamps and deterministic evidence content hash;
- write-once/idempotent persistence and conflicting-rewrite rejection.

The source learner artifact's original training window is not required to equal the
prepared input window. The source artifact identity and provenance remain strict; the
output artifact must match the prepared run's exact input window.


No default trainer, hidden ML dependency, filesystem loader, network call, exchange
client, training trigger, qualification gate, promotion mutation, paper activation,
or order route was added. No actual learner model was generated by this phase's
production code; the contract requires a caller-supplied trainer and is ready for a
separate explicit integration.
